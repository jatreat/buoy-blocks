# Buoy Blocks

A relaxing block puzzle set on a Maine lobster wharf. Drag pieces onto the 8x8 board, fill a row or column to clear it, and keep going as long as you can find room. Every block is painted like a lobster buoy.

- Clear several lines at once for big points ("Wicked good!" and "Finest kind!")
- Keep clearing to build a combo multiplier, and clear the whole board for a bonus
- Unlock 6 harbor themes by beating your best score

`index.html` is the complete game (one file, CrazyGames HTML5 SDK v3). `covers/` and `videos/` hold the store art.
